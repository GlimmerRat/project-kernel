## Objective

Build an AI-enabled workflow platform for boutique capital advisory firms, using automation to support deal sourcing, valuation, investor matching, diligence, and execution.

## Current state

The first module is intended to be a Deal Dashboard, with an architecture that can share reusable primitives with CatVal without forcing both products into one application.

## Current milestone

Define the Deal Dashboard MVP and the shared-backbone boundary.

## Open questions

- Minimum useful Deal Dashboard scope.
- Which primitives should be shared with CatVal.
- Data model for deals, investors, diligence, and workflow state.
