## Objective

Build a reusable toolbox of legal-computing primitives for bespoke legal-tech systems, preferring deterministic and programmatic methods where sufficient and using AI only where probabilistic methods add genuine value.

## Current state

Core design principles are established, including deterministic-first workflow design and an embedding pipeline for semantic retrieval, playbook sense-checking, and historical deviation analysis.

## Current milestone

Define the first MVP primitives and choose the initial implementation environment.

## Open questions

- Solveit notebook vs Codex-led implementation.
- Initial primitive set and boundaries.
- Embedding/retrieval interface.
